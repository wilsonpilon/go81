# ROMs

As ROMs do EightyOne 1.41 para a família ZX81 (as do ZX Spectrum ficam de fora do Go81).

| Arquivo | Máquina | Uso no Go81 |
|---|---|---|
| `zx81.edition1.rom` | ZX81, ROM edição 1 (com o bug de ponto flutuante) | modelo `zx81` |
| `zx81.edition2.rom` | ZX81, ROM edição 2 | modelo `zx81` |
| `zx81.edition3.rom` | ZX81 / TS1000, ROM edição 3 (padrão) | modelos `zx81` e `ts1000` |
| `ts1500.rom` | Timex Sinclair 1500 | modelo `ts1500` |
| `tk85.rom` | Microdigital TK85 (10K) | modelo `tk85` |
| `ringo470.rom` | Ringo R-470 | modelo `r470` |
| `zx80.rom` | Sinclair ZX80 | futuro modelo `zx80` |
| `lambda8300.rom`, `lambda8300colour.rom`, `pc8300timex.rom` | Lambda 8300 / PC8300 | futuro modelo `lambda` |
| `zx97.rom` | ZX97 Lite (32K, com bancos) | futuro modelo `zx97` |
| `jupiterace.rom` | Jupiter Ace | futuro modelo `ace` |
| `tree-forth.rom`, `zx81-forth.rom` | Forth no lugar do BASIC (ZX81, TS1000, TS1500) | ROM alternativa |
| `zx.aszmic.e04.rom`, `zx.aszmic.e07.rom` | ASZMIC (montador/monitor no lugar do BASIC) | ROM alternativa |

As ROMs da Sinclair são © Amstrad plc, que permite sua distribuição para uso em
emuladores, desde que não sejam vendidas. As da Timex, Microdigital, Ringo,
Lambda, Jupiter Cantab e as alternativas são distribuídas com o EightyOne e
seguem aqui pelo mesmo motivo: os fabricantes não existem mais e as ROMs são
de uso corrente em emuladores. Nenhuma delas faz parte do código do Go81 nem
está coberta pela licença GPL do projeto.
